# AI Tools

企业 AI 工具平台脚手架，基于 Vite、React、Ant Design、ahooks、dayjs 与 React Router。

## 开发命令

```bash
pnpm --filter @x-dev-assistants/ai-tools dev
pnpm --filter @x-dev-assistants/ai-tools build
pnpm --filter @x-dev-assistants/ai-tools preview
```

## 目录结构

```text
src/
├── components/     # 通用布局与组件
├── pages/          # 页面模块
├── routes/         # 路由配置
├── styles/         # 全局样式
└── utils/          # 工具数据与通用函数
```
